# AGENTS.md

## Cursor Cloud specific instructions

### What this repo is
This repository is the **NVIDIA RTX Global Illumination (RTXGI / DDGI) plugin for Unreal Engine 5.7**.
It is a single Unreal Engine plugin, **not** a web/service app or monorepo:
- C++ UE modules: `RTXGI` (Runtime) and `RTXGIEditor` (Editor, `Win64` only) under `Source/`.
- HLSL ray-tracing / compute shaders (`.usf` / `.ush`) under `Shaders/`.
- Plugin manifest: `RTXGI.uplugin`.

There is **no package manager, no lockfile, no test suite, no lint config, no CI, and no build scripts**
in this repo. `Binaries/` and `Intermediate/` are generated by Unreal and are git-ignored.

### Build / lint / test / run — requires Unreal Engine (cannot run on the Linux cloud VM)
This plugin is built by **Unreal Build Tool (UBT)**, which ships with Unreal Engine. It is **not**
standalone-buildable with clang/cmake. Building requires all of the following, none of which exist on
the Linux cloud VM:
- **Windows 10 1809+** (the `RTXGIEditor` module whitelists only `Win64`; `RTXGI.Build.cs` treats only
  `Win64` as a supported platform).
- **Unreal Engine 5.7** installed with engine source (build references `EngineDirectory` and internal
  paths like `Engine/Source/Runtime/Renderer/Private`). Requires an Epic Games account + EULA.
- A **DirectX 12 + DXR (ray tracing) capable GPU** for runtime (the cloud VM is headless with no GPU).
- A **host UE project** to install the plugin into (`<Project>/Plugins/RTXGI/`).

Because of the above, there is **nothing to build, lint, test, or run inside a Linux cloud agent VM**.
Do not attempt to `clang++`/`cmake` the sources directly — they depend on UBT include paths and UE
engine headers and will fail with missing-header errors.

Standard end-to-end usage (on a Windows workstation, not this VM) is documented in `README.md`:
1. Copy this repo into `<YourProject>/Plugins/RTXGI/`.
2. In Project Settings set Default RHI = DirectX 12 and enable Ray Tracing.
3. Enable the "NVIDIA RTX Global Illumination" plugin; set `r.DynamicGlobalIlluminationMethod 4` (UE 5.x)
   and `r.RTXGI.DDGI 1`.
4. Build via `Engine/Build/BatchFiles/Build.bat <Project>Editor Win64 Development -Project=...` and launch
   `UnrealEditor.exe`, then place `DDGIVolume` actors.
5. Plugin-only packaging: `RunUAT.bat BuildPlugin -Plugin=RTXGI.uplugin -TargetPlatforms=Win64 ...`.

### Update script
There are no installable dependencies (no manifests, no submodules), so the startup update script is a
no-op. Do not add engine/GPU installation to it — that is out of scope for an automatic startup layer.
